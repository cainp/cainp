##  Projetos em Destaque

### [Android System Monitor](https://github.com/cainp/android-monitor)
Aplicativo nativo para monitoramento de recursos (CPU, Memória, Bateria) em tempo real.
- **Foco:** Uso de `ActivityManager` e `BatteryManager`.
- **Destaque:** Investigação de vazamentos de memória via Logcat e ADB.

### [Analisador de Logs Android via CLI](https://github.com/cainp/android-log-analyzer)
Script em Python para triagem rápida de problemas no framework.
- **Foco:** Parse de `logcat` e `bugreport`.
- **Destaque:** Implementação de filtros por PID/Tag e agrupamento de erros recorrentes para debugging.

### [Simulador de Escalonador de Processos](https://github.com/cainp/process-scheduler)
Simulador de algoritmos de SO (Round Robin, FCFS, SJF) desenvolvido em C++.
- **Foco:** Gerenciamento de processos e métricas de throughput.
- **Destaque:** Base teórica para compreensão do gerenciamento de processos no nível do sistema.
